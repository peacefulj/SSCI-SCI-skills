PM PaperMate v1.3.0
规则驱动的学术论文写作决策 + 审查助手

论文全程陪跑，从选题到投稿返修

这不是一个"会写论文的通用 AI"，而是一套有据可查、可追溯、可判定的写作规范库（393 条规则，逐条含出处与正反例句）。本助手识别你的学科与体裁后，加载对应规范，词面检测 + 大模型逐条判读，给出可执行的结论。

⚠️ 尚未配置 API Key，深度判读、六阶段引导与一键成稿将无法使用。点右上角「设置」填写（DeepSeek / Anthropic / 萤算 任选一家）。

能力边界（使用前必读）

不支持纯理论数理类论文
数学 / 理论物理 / 理论经济等"定义-定理-证明"结构文章不支持——规则库基于 IMRaD（摘要/引言/方法/结果/讨论），理论文章无"实验/结果"章节，硬套会系统性误判。
基础科学、临床两条线可信度较低
规则已建立但未做真实全文校验。定量实证、质性研究两条线最可靠（已用 12 篇真实论文逐条核对）。
不覆盖领域表征标准
ACS Style Guide、IUPAC 命名、晶体学 CIF 等领域标准不在规则库内，须核对目标期刊作者指南。
一键成稿产出的是工作稿
它保证结构、章节与表达符合规则库，但不会替你有数据、有文献、有真实结果：正文里的 [TBD: ...] 必须用真实数据填，[CITE: ...] 必须换成可核实的文献。英文优先，中文为受限通道。
AI 生成内容带水印，不可直接使用
本应用产出的一切文本都是 AI 生成内容，平台导出或转存的副本可能带可见/不可见的 AI 标记（水印、隐写标识、元数据）。严禁把带水印的成稿用于投稿、交稿或发表——会被期刊的 AI 检测判定为代写，且隐写标记无法通过转存、截图、复制粘贴去除。正确用法：只当写作骨架，逐段用自己的语言重写，数据与文献全部换成真实可核实的。
词面检测 ≠ 审查结论
全库 393 条规则中仅 95 条可词面自动判定，其余约 298 条需大模型对照 signal 逐条判读。本应用两者都做：词面即时检测 + 大模型深度判读。

支持的学科主线

规则数 = 该主线适用的规则总量（含共用规则）。"自动"= 有词面检测器的规则，"人工"= 需大模型判读的规则。

选题定位

判断"做什么方向、值不值得做"，引导产出可回答、可证伪、有变量的研究问题，以及"现有文献缺什么、为什么现在能做"的 gap 论证。

选题雷达（OpenAlex 发文趋势 + AI 三维评估）— 选题的常规一步

先跑趋势看这个方向近几年热度变化，再让 AI 给 3 个候选题目和三维打分（新颖性 / 可行性 / 数据可得性，标准随学科主线与层级变化）。不填检索词也能跑：留空即用上方研究方向。

研究设计评审

按学科主线校验设计是否成立：识别策略（工具变量/断点/双重差分/固定效应）、内生性来源、抽样与样本量、对照组、数据可复现性。

初稿写作引导

按引言 / 方法 / 结果 / 讨论逐段给框架与改写范例，每条规则自带正反例句（example_bad / example_good）可直接当范本。

引用格式规范

四套引用体系（IEEE / APA 第7版 / GB/T 7714 / 脚注制）怎么选、怎么改，避免"[1]编号+字母序"这类中英混排（CIT 族共 16 条规则）。

投稿前审查

本助手最成熟的场景：结构自检 + 词面检测 + 大模型逐条判读 + 三层风险清单。

1 · 选学科确定学科主线与体裁，加载对应规则
2 · 上传稿件上传 Word / Markdown / LaTeX，或直接粘贴全文
3 · 词面检测复用 skill 原生脚本即时出词面结果
4 · 深度判读大模型逐条判读需人工的规则
点击或拖拽上传 Word(.docx/.doc) / Markdown / LaTeX / PDF / TXT，或直接在下方粘贴全文（表格、公式、图片会一并解析）
深度判读会把约 30 条需人工的规则逐条交给大模型对照 signal 判读，通常需 1~3 分钟，请耐心等待。

投稿与返修

产出投稿包清单（cover letter、标题页、伦理声明、数据可用性声明、报告规范清单），返修时产出 rebuttal 结构（逐条回应 + 改动定位 + 不改的理由）。

一键成稿（学术小白）

从选题 → 定题 → 研究设计 → 大纲 → 分章成稿 → 文献装配 → 自检，一次跑完，产出一篇符合规则库结构要求、引用可核实的工作稿。规则库基于国际期刊规范（SCI / SSCI / EI / AI 会议），默认英文，中文为受限通道。

⚠️ 严禁把 AI 生成内容的水印稿用于投稿、交稿或任何实际用途。 本应用产出的全部文本均为 AI 生成内容；平台侧的分发、导出或转存副本可能带有可见或不可见的 AI 标记（水印 / 隐写标识 / 元数据标签）。这类稿件存在三类实际风险：
  1. 学术不端认定：期刊与高校已有 AI 检测与标记核查机制，带标记的稿件会被判定为 AI 代写。
  2. 版权与署名争议：带水印的副本无法证明你的原创贡献，也可能违反目标期刊的 AI 使用声明。
  3. 技术性暴露：隐写标记肉眼不可见，PDF 转存、截图、复制粘贴都不能清除。
正确用法：只把产出当作写作骨架与自查清单，逐段用自己的语言重写、用真实数据填充 [TBD: ...]、用可核实文献替换 [CITE: ...]，最终稿必须是你自己重新写出的文本。不要使用任何带 AI 水印的成稿直接提交。
这不是「一键投稿」。生成的是工作稿：[TBD: ...] 处必须由你用真实数据填写，[CITE: ...] 由第 6 步「文献装配」用 OpenAlex 真实检索结果替换：每条都带 DOI、可点开核对；检索不到就保留占位并写明原因，绝不编造作者与年份。不编数据、不造文献，是这套流程的硬约束。
