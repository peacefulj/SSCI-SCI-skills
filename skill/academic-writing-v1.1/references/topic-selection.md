# 选题环节：选题雷达（OpenAlex 趋势 + AI 三维评估）

> 本文件是 academic-writing skill 的**选题环节**规范，能力移植自研墨平台 v1.10.0 的「选题雷达」。
> 定位：在用户还没确定研究问题、处于"做什么方向 / 值不值得做"阶段时，agent 用它引导用户完成一次**有数据支撑 + 有评分依据**的选题。

---

## 一、选题三步法（agent 执行顺序）

```
① 定范式 + 层级 → ② 跑 OpenAlex 全球发文趋势 → ③ AI 三维评估选题
```

### 第 1 步：定范式（学科主线）与层级

先确认用户属于哪个 **track（范式）** 与 **层级**，这决定后续评分维度怎么算。

| track | 范式 | 描述 |
|---|---|---|
| `quant` | 定量实证 | 经济、管理、金融、社会学定量 |
| `ei-conf` / `ai-conf` | 工程技术 | 计算机、电子、机械、土木、人工智能 |
| `clinical` | 医学临床 | 临床医学、护理、公共卫生 |
| `qualitative` | 质性研究 | 社会学、教育学、人类学、管理案例 |
| `basic-science` | 基础科学实验 | 化学、生物、材料、物理实验 |
| — | 理论·数理 | 数学、理论物理、理论经济（⚠️ 本 skill 规则库不支持，选题评估可做但后续审查不覆盖） |

层级（`WQ_LEVELS` 对应）：本科毕设 / 硕士论文 / 博士论文 / 期刊投稿 / 一般性研究。

**评分维度随范式与层级变化**——具体每维的评价标准见 `references/topic-scoring-dimensions.md`，这是本环节最关键的资产，agent 拼评估提示词时必须按用户的范式+层级取对应片段。

### 第 2 步：跑 OpenAlex 全球发文趋势

**目的**：用真实发文量判断"这个方向是在升温、平稳还是回落"，避免拍脑袋选题。

**做法**（agent 可直接调用脚本，或手工拼 OpenAlex 请求）：

```bash
python scripts/topic_radar.py "移动支付与农户创业"
python scripts/topic_radar.py "negative beta strategy"
```

脚本内部逻辑（`scripts/topic_radar.py`）：

1. 调 `https://api.openalex.org/works?filter=title_and_abstract.search:{topic},from_publication_date:2021-01-01&group_by=publication_year`
2. 若首次无结果，降级用 `search={topic}` 兜底
3. 得到逐年发文量，画文本柱状图
4. 计算「2021 → 最近完整年」的增长率（**排除当前年**，因当年发文不完整）

**趋势判读阈值（三档，忠实沿用研墨）**：

| 增长率 | 判读 | 对选题的含义 |
|---|---|---|
| > +20% | 🔥 快速升温赛道 | 方向活跃、可跟，但要找差异化切入点，避免红海同质 |
| −20% ~ +20% | ⚖️ 平稳领域 | 成熟稳定，选题价值要靠"边际贡献是否清晰"支撑 |
| < −20% | 📉 热度回落 | **提示选题必要性存疑**：要么是问题已解决，要么是该问法已过时，须向用户点明 |

> 注意：OpenAlex 是英文库，中文主题须先转英文检索词（如"移动支付与农户创业"→ "mobile money rural entrepreneurship"），否则命中会很少。

### 第 3 步：AI 三维评估选题

**目的**：让 AI 基于"趋势数据 + 范式评分标准 + 层级创新标尺"给选题打分，产出可用的选题报告。

agent 拼装评估提示词的完整模板在 `assets/topic-prompts.md`，核心结构：

1. **三个候选题目**（每题一句话：研究角度 + 创新点）
2. **每题三维打分**：新颖性 / 可行性 / 数据·材料可得性（各 1-10 分，各一句理由）
3. **数据与文献可得性清单**（需要什么数据/材料 + 核心文献大概在哪些库）
4. **主要风险与规避建议**（2-3 条）

**三维是固定的，但每维的评价关切随范式/层级变**（这是"评分维度随范式与层级变化"的确切含义）：

| 维度 | quant 的关切 | qual 的关切 | eng 的关切 |
|---|---|---|---|
| 新颖性 | 边际贡献是否清晰、识别策略是否有增量 | 理论对话对象是否清晰 | 相对 SOTA 的提升空间 |
| 可行性 | 识别策略成立、内生性风险可控 | 田野/样本可得性、进入方式 | 数据集/算力可得性、复现性 |
| 数据·材料可得性 | 关键变量是否能在现有库找到 | 研究对象/场所能否进入 | 数据集/评测基准是否可得 |

> 6 个范式的完整 evalFocus 与 5 个层级的 innovation 标尺，见 `references/topic-scoring-dimensions.md`。

## 二、gap 论证（选题落地的最后一公里）

AI 评估产出候选题目后，agent 须帮用户把"题目"收敛成"可写的研究问题"，即完成 gap 论证。判断标准（对应规则库 `WRI-INT-002`）：

**一个合格的 gap 论证必须同时说清三件事**：
1. 现有文献**做了什么**（不是罗列，是按观点/流派归类）
2. 现有文献**缺什么**（缺口 = 理论/方法/数据/情境中的具体空白）
3. 为什么**现在能做**（新数据、新方法、新情境使其可行）

**反例（不合格）**："移动支付研究很多，但农户创业这块研究较少" —— 只有"少"，没有"为什么少"和"为什么现在能做"。

**正例（合格）**："已有移动支付研究聚焦肯尼亚 M-Pesa 的风险分担（Jack & Suri, AER 2014）与减贫（Suri & Jack, Science 2016），但多为跨国截面，且以消费平滑为因变量；国内数字金融对农户创业的作用机制（是缓解信贷约束还是降低交易成本）仍缺乏基于面板数据的因果识别——而 2020 年后县域数字金融指数与农户微观调查面板的公开，使这一识别首次可行。"

## 三、选题环节的输出物（agent 交付清单）

完成选题后，agent 应产出：

1. **选题评估报告**（AI 三维评估的完整输出，含 3 候选题 + 打分 + 风险）
2. **趋势判读结论**（升温/平稳/回落 + 一句话含义）
3. **gap 论证段落**（可写进引言第一段的初稿）
4. **选定题目的一句话陈述**（作为进入"研究设计"环节的输入）

---

## 四、与其他环节的衔接

- 选题 → **研究设计**：选定题目后进入 `references/genre-*.md` 对应范式的研究设计校验（识别策略/实验设计/抽样逻辑）
- 选题评估报告存为项目资料，**研究设计与写作生成时会复用**（范式、层级、目标期刊、gap 论证）

---

## 五、边界与诚实声明（必须告知用户）

- **趋势数据来自 OpenAlex**，只覆盖其收录的文献（英文为主），中文主题须转英文检索，且是"题名+摘要匹配"口径，不等于该主题的精确发文量。
- **AI 三维评估是启发式建议，不是替代判断**：打分是"按当前范式/层级的审稿口径"给的相对参考，最终选题决策仍由用户自己定。
- **理论·数理范式**：选题评估可做（有 evalFocus），但本 skill 规则库**不支持**后续的理论论文审查（IMRaD 章节枚举不兼容 definition–theorem–proof），须提前告知。
