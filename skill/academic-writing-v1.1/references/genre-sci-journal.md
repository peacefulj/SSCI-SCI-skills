# SCI 期刊论文 Playbook

来源：Robert A. Day & Barbara Gastel, *How to Write and Publish a Scientific Paper* 9e (Greenwood, 2022)。链路状态：规则已入 rules.yaml（WRI-* 中 genre 含 sci-journal 的 74 条，source 标注 Day & Gastel 章节页码）。

## 与其他体裁的核心差异

- **结构固定 IMRaD**：Introduction / Methods / Results / Discussion（可夹认为 A 段 Acknowledged）；长文、有 abstract、常有 graphical abstract 与 highlights（ch.2, ch.9）
- **有 cover letter + 多轮 revise-and-resubmit**：投稿包装较会议更重，返修是常态而非例外（ch.10, ch.13）
- **评审更看重"可复现的完整方法"**：Methods 必须写到"读者可重复"；Results 客观、Discussion 解释（ch.11, ch.12）
- **伦理红线硬**：作者署名、一稿多投、自我剽窃/切片发表、图像与数据真实性（ch.20, ch.21）

## 篇幅与结构（IMRaD）

| 部分 | 要点 | source |
|---|---|---|
| Title | 具体、含方法与任务，避免 "A Study of..." | ch.8 |
| Abstract | 四要素：问题、不足、方法、量化结果；不用未定义缩写、不引文献 | ch.9 p.60-62 |
| Introduction | 漏斗推进，必有 gap 句（However...），贡献明确可识别 | ch.5 p.27-32 |
| Materials & Methods | 完整到可复现：材料/数据/实验程序/统计方法，越细致越好 | ch.11 p.72-74 |
| Results | 只呈现数据，不解释；图表统一、不重复；报"异常/负结果" | ch.12 p.77-79 |
| Discussion | 先答研究问题，再解释同意/分歧、机制、局限性、意义 | ch.10 p.70, ch.9 |
| Conclusion | 从 Discussion 提炼，不新增结论，补 2-3 条局限性 | ch.8 |

## 各部分写作要点

### 标题（ch.8）
- 具体、信息量大：含方法、任务、对象；避免空泛词（investigation/study/contributions）
- 长度与招标风格一致，不用缩写、不用副标题堆砌

### 摘要（ch.9）
- 3-4 句：问题 → 现有不足 → 本文方法 → 数字结果
- 首次出现缩写写全称；不写 "We review relevant literature"

### 引言（ch.5）
- 漏斗：背景 → 具体问题 → 现有方法 gap → 本文做法 → 贡献
- 贡献 3-4 条可验证；结尾同时出现 gap 句 + 方法 + 贡献

### 方法（ch.11）
- 完整到"他人可复现"：数据来源/规模/采集、实验设计、统计口径
- 社会/生物类另写伦理审批、样本纳入排除标准

### 结果（ch.12）
- 只呈现、不解释；选图或表其一，不重复
- 负结果、异常值照实报告；不做选择性呈现

### 讨论（ch.10）
- 结构：答研究问题 → 与文献相符/相悖 → 机制解释 → 局限 → 意义/推广
- 主动写 limitations，审稿人会据此加分

## 投稿包（cover letter + 附件）

- **Cover letter**：一句点题 + 为何合适本刊 + 关键结果 + 声明（原创、未一稿多投、无利益冲突）
- **Highlight/Graphical abstract**：期刊要求时提供
- **推荐/回避审稿人**（如刊方允许）

## 返修（revise & resubmit）

- 逐条回应审稿人与编辑；每个点落到"已改于 Lxx"或"不采纳 + 理由"
- 区分 major/minor；回应语气克制、专业，不过度辩护

## 伦理红线（ch.20-21）

| 问题 | 判定 |
|---|---|
| 一稿多投（duplicate submission） | 同时投多刊违规；分区发表前须告知编辑 |
| 自我剽窃 / 切片发表（salami slicing） | 同一研究切碎多发，需公开说明重叠并引用 |
| 作者署名 | 所有署名须实质贡献；避免 gift/ghost authorship |
| 数据/图像真实 | 不拼图、不造假、不选择性删除；原始数据可追溯 |
| 利益冲突与引用 | 披露资金来源与利益冲突；恰当引用而非过度自引 |

## 投稿前自检

- [ ] 结构是否 IMRaD、各部分边界清晰（Results 不解释、Discussion 不新增结果）
- [ ] Methods 是否完整可复现
- [ ] 每类结果是否都有 Discussion 对应解释与局限
- [ ] 伦理项（署名、原创性、一稿多投、利益冲突）是否清白
- [ ] Cover letter 是否点明"为何本刊 + 关键结果 + 声明"
