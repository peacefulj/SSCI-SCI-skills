# 博士大论文 Playbook

来源：Evans, Gruba & Zobel, *How to Write a Better Thesis* 3e (Springer, 2014)

## 大论文 vs 期刊论文的核心差异

- **考察的是人，不是研究本身**：考官依据"考试准则"逐条评估你是否"完成了研究学徒期、具备进入学术共同体的资格"；论文是"考试答卷"，不是研究报告（ch.1 p.1–2）
- **篇幅与深度**：博士论文通常约 8 万字、3 年全职，是"careful, rigorous and sustained"的持续性作品；深度比广度重要（ch.1 p.4）
- **多贡献需一条主线**：工程/部分社科领域论文常由若干已发表的子贡献拼成，但必须有一条贯穿全文的 narrative/argument 把各章串起来，否则只是"论文合集"（ch.2 p.13–14, ch.7 p.83）
- **读者是"挑剔的考官"**：考官按 8 个问题逐条检查（文献熟悉度、方法是否得当、结果呈现、结论是否与 aim 对齐、是否构成 substantive original contribution）；因此要"防御式写作"（ch.1 p.2–3, ch.6 p.77）
- **无标准模板，但有标准结构**：没有两本一样的论文，但所有论文都遵循 intro → background → core → synthesis 的四段骨架（ch.2 p.11）
- **本质是"可辩护的论证"**：论文 = extended argument，靠可信、可验证的证据支撑，最终做出"原创贡献"（ch.1 p.1）
- **读者群极小但极挑剔**：真正通读全文的只有导师、两位外审专家和少量同行；写的时候心里要有"那个具体的考官"（ch.1 p.1, ch.6 p.77）

## 典型章节结构

四段式骨架（ch.2 p.11–12）：**引言 → 背景 → 核心（自己的贡献）→ 综合（讨论+结论）**。各段显式相连：结论逐条回应 aim，背景必须预示核心。

```
Chapter 1  引言（Introduction）
Chapter 2–4 背景（Background）——文献综述、当前理论/实践、初步调查
Chapter 5–8 核心（Core）——假设/RQ、方法、结果、分析（占论文一半以上）
Chapter 9   讨论（Discussion）
Chapter 10  结论（Conclusions）
```

各章功能：

| 部分 | 功能 | 关键点 |
|---|---|---|
| 引言章 | 建立 context → 陈述问题 → 单一 aim → scope → significance → 概览 | aim 必须唯一；RQ 宽泛表述即可；不用 "hypothesis"（ch.5） |
| 背景章 | 把读者从"过去已知"带到"知识前沿" | 是"engage（对话）"而非"report（罗列）"，收尾点明 gap（ch.6） |
| 贡献/方法章 | 陈述假设/RQ → 方法选择与理由 → 实验设计 | 方法、测量指标都要给 justification；主动排查 confound（ch.7） |
| 结果章 | 呈现证据、把数据变成 argument | 只报结果，解读留给讨论（ch.8） |
| 讨论章 | 从结果中提炼结论、回应 aim | 结论必须"从讨论中来"；主动写 limitations（ch.9） |
| 结论章 | 只从讨论章抽取结论，逐条回应 aim | 2–3 页，简短有力；summary ≠ conclusion（ch.10） |

章节数量：**5–10 章**。超过 10 章多半是把"节"误当成"章"，需合并（ch.2 p.13）。

**叙事（narrative）**：结构是"材料的组织"，叙事是"读者思维的走向"——把读者从"过去的已知"领到"知识前沿"。写的时候设想"开始研究前的自己"就是你的读者；narrative 与 structure 别混为一谈（ch.2 p.14）。

**防御式写作**：预判考官会误解/质疑的地方并提前澄清。常问自己："如果我粗读一遍、或不熟背景文献，会犯什么错？"然后改正文帮读者避开（ch.6 p.77）。

## 章节写作顺序建议

- **先写引言章定 aim**：用写作驱动阅读与研究——把 aim/scope 写下来，才能与导师争论、打磨论证（ch.4 p.44, ch.7 p.90）
- **背景章优先且要早**：最难写（要读上百篇文献、逐个判断贡献与缺陷），也最常回头改；背景草稿在手，其余章节会顺很多（ch.4 p.45）
- **卡壳时先写"事实型"章节**：研究区域描述、方法选择理由、实验/问卷设计——理性成分高、不易卡（ch.4 p.44–45）
- **每章先搭"引言+结论"骨架**：把各章引言串起来读一遍，看整篇是否逻辑推进（ch.4 p.44, ch.9 p.119）
- **尽早写、别等到实验做完**：等"research first, write later"会丢掉叙事，考官会问"为什么做这些实验、有什么意义"（ch.4 p.44）
- **引言章要反复回改**：aim 会随着研究漂移，定期回读引言、同步结论，避免"承诺了却没交付"（ch.5 p.70）

## 写作过程（从卡壳到成稿）

- **写作 = 理性结构 × 创作性**：研究/写作都是"创意+理性"的拉锯；先搭好逻辑结构（各章引言串起来），再让创作部分自由发挥，之后二者互相校正（ch.2 p.10, ch.4 p.46）
- **写不出来就"粗写"**：放下对每句话的反复挑剔，先快速把想法落到纸上，之后大改；纠结单句是 writer's block 的典型形态（ch.4 p.47）
- **用写作驱动阅读**：把没读的论文列在计划讨论它们的位置，背景就会从"待读清单"长成"已读分析"（ch.4 p.44）
- **别陷入"重写死循环"**：反复推翻开头、想一次到位会永远定不了 aim——强迫自己选定一个方向推进，边写边修正 aim（ch.4 p.45–46）
- **日拱一卒 + 隔夜再看**：当天写完存稿，第二天先读大纲再读全文，理性与创意冲突处二选一（改结构或删跑题内容）（ch.4 p.46）
- **卡住就跟人讲一遍**：找不熟悉你领域的人听你讲工作，讲出来的内容就是章节草稿（ch.4 p.47）
- **成稿是马拉松不是冲刺**：PhD 需多年稳定节奏，保持常规作息与生活，不要 70–80 小时/周地硬冲（ch.12 p.147–148）

## 创新点与贡献的表述

- **先定位贡献类型**：在几条维度上给自己定位——观察 vs 创新、study vs case study、理论 vs 应用。定位决定叙事结构（ch.7 p.84–85）
- **创新 = 创新 + 评价标准**：创新类论文要写"该创新预期有什么性质、需满足什么标准"，这些与描述共同构成"假设"（ch.7 p.85）
- **定位需要 justification**：选 case study 就要论证"为何选这个案例、它代表什么更大的现象"；case study 的 aim/title 不应混入具体案例名（ch.7 p.86–87）
- **考官如何评估贡献**：8 问最后一条——是否构成"substantive original contribution"；靠前面各问（文献、方法、结果、结论对齐）共同支撑（ch.1 p.2–3）
- **方法选择 = 贡献的一部分**：即使用了标准方法也要说明"为什么选它"；用多方法（triangulation）要说明"为什么一种不够"（ch.7 p.88–89）
- **测量指标要自证**：别用"吨数、销量"这类指标而不给理由；列出备选指标并说明取舍（ch.7 p.90–91）

## 与导师的协作

- **关系会演进**：从"师徒"走向"同行"；但 write-up 阶段论文是你个人的责任，导师不是作者（ch.4 p.55）
- **对进展要诚实**：隐瞒问题会切断获得帮助的可能；导师是 mentor 不是权威（ch.4 p.56–57）
- **分章提交、别一次甩整本**：让导师逐章反馈，反馈回来你还能继续写；整本会给导师拖几个月（ch.11 p.125–126）
- **对反馈独立思考**：导师意见是 guidance 不是指令；看不懂或有异议要分析后沟通，不要盲从也不要全盘推翻（ch.11 p.126–127）

## 考官评估的 8 个问题（自评框架）

提交前逐条自问（ch.1 p.2–3，澳洲博士外审通用）：

1. 是否熟悉并**批判性**评述了相关文献？
2. 对主题的考察是否足够全面？
3. 方法是否适合主题、是否论证充分且应用得当？
4. 结果是否清晰呈现、附有充分阐释？
5. 结论与意义是否与研究的框架和发现明确挂钩？
6. 研究问题是否真的被检验了？
7. 文笔与整体呈现是否达标？
8. 论文整体是否构成**实质性原创贡献**？

前 7 条是第 8 条（原创贡献）的支撑，也是结构自查的天然 checklist。

## 答辩 / 口头报告

> 本书为澳洲语境：博士论文由外部考官书面评审（通常无 viva），口头环节主要是院系 seminar / 会议报告。以下适用于答辩前报告与论文陈述。

- **报告 ≠ 论文复述**：30 分钟讲不完一本论文，目标是讲清"为什么有趣、哪里新、有什么意义"，让人想去读全文（ch.12 p.144）
- **结构**：problem/aim → 精简背景 → 自己的 findings → implications；末次报告重心放在发现与意义（ch.12 p.143）
- **原则**：① 把报告当作"与受过教育的朋友的对话"；② 报告讲工作本身而非复读全文；③ 对听众仁慈——快进叙事、不看稿、不背对听众（ch.12 p.143–145）
- **备答即备写**：预演考官 8 问（文献、方法、结果、结论对齐、原创贡献），把回答写进论文相应章节（ch.1 p.2–3）

## 常见问题与自检

考官眼中的常见缺陷，提交前逐条打勾：

- [ ] **95% 综合征**：默认读者（考官）和我一样懂基础概念，只写那 5% 的新东西——背景章要写给"开始研究前的自己"（ch.6 p.76–77）
- [ ] **日记式章节**：按实验顺序平铺直叙，没有动机、解释、论证——重组为"aim → evidence → conclusion"（ch.2 p.10–11）
- [ ] **章节结尾只列内容**：写"本章讲了 A、B、C"却没有 significance——改成"本章确立了什么新东西"（ch.4 p.50, ch.11 p.128）
- [ ] **aim 不唯一**：一句 aim 里塞三四个目标——只留一个，其余降为方法步骤（ch.5 p.65）
- [ ] **结论不回应 aim**：把 problem + aim + conclusion 连起来读，读不通就是没对齐（ch.5 p.65, ch.10 p.122）
- [ ] **summary 冒充 conclusion**：总结是"发现了什么"，结论是"这有什么意义"——补上 significance（ch.10 p.123）
- [ ] **无 limitations**：全文没有不足/局限段，或 case study 不谈可推广性——补上，且用非道歉口吻（ch.9 p.117–118）
- [ ] **方法/指标无理由**：只说"用了 X"不说"为什么"；指标不加论证——补选择理由与 confound 排查（ch.7 p.89–91）
- [ ] **章节无头无尾**：某节突然出现、与上下文无关——每个组件都补"头（引入）尾（小结）"（ch.11 p.128–129）
- [ ] **结论章新增未论证结论**：结论只应来自讨论章，若想写新结论先补进讨论（ch.10 p.122）
- [ ] **背景章"罗列"而非"对话"**：把文献一段段总结却没有评点其贡献、也没推进到 gap——改成 interweave 各家研究、收尾点明未解决问题（ch.6 p.77–78）
- [ ] **引言语焉不详、缺 aim**：读完引言仍不知道要干什么——按 context→problem→单一 aim→scope→significance 补齐（ch.5 p.61–67）
- [ ] **引言章过长**：引言不是文献综述，5–10 页足矣；长引言多半是把背景章内容提前塞进来了（ch.2 p.12）
- [ ] **忽视初步调查的价值**：背景章可以含初步实验/调查来建立 benchmark、探路——缺了会让核心章缺少铺垫（ch.2 p.12）
- [ ] **混淆 method 与 methodology**：method = 具体技术，methodology = 研究者的立场/范式；社科/人文需另节说明 stance（ch.7 p.88–89）
