# AI 选题评估提示词模板库

> 本文件提供「AI 三维评估选题」的提示词骨架，供 agent 现场拼装。
> 拼装规则：`通用骨架 + 范式 evalFocus 片段 + 层级 innovation 标尺 + 趋势数据`。
> 评分维度标准（evalFocus / innovation 的原文）在 `references/topic-scoring-dimensions.md`。

---

## 一、通用评估骨架

```
你是科研选题评审专家（{范式名}范式，{范式 venueHint}）。研究主题：「{选题}」。
全球发文趋势（年份:篇数）：{趋势数据，如 "2021:312, 2022:358, 2023:401, 2024:455"；未跑趋势则写"未跑趋势"}。

{范式 evalFocus 片段}

用户层级：{层级名}——创新标尺：{层级 innovation 片段}。文献规模预期：{层级 lit}。

请输出一份选题评估报告，包含：
一、三个候选题目（每题一句话说明研究角度与创新点，编号 1-3）
二、每个题目打分：新颖性(1-10)、可行性(1-10)、数据/材料可得性(1-10)，各一句理由
三、数据与文献可得性清单：这个题目需要什么数据或材料、核心文献大概在哪些库
四、主要风险与规避建议（2-3 条）

用简体中文，条理清晰，可直接作为选题报告使用。
```

## 二、范式 evalFocus 片段（按 track 替换 `{范式 evalFocus 片段}`）

| track | 范式名 | venueHint | evalFocus 片段 |
|---|---|---|---|
| `quant` | 定量实证 | JF/JFE/RFS 或国内顶刊口径 | 选题评估侧重：识别策略的可行性与数据可得性、边际贡献是否清晰、内生性风险。 |
| `ei-conf`/`ai-conf` | 工程技术 | CCF 推荐列表或领域顶会/顶刊口径 | 选题评估侧重：相对现有方法的性能提升空间、数据集/算力可得性、复现性与创新点可验证性。 |
| `clinical` | 医学临床 | 中华系列/SCI 收录期刊口径 | 选题评估侧重：临床意义（PICO 是否清晰）、伦理与可行性、样本量、对指南或实践的潜在改变。 |
| `qualitative` | 质性研究 | 领域权威期刊口径（如社会学研究、教育研究） | 选题评估侧重：研究问题的质性适配度、田野/样本可得性、理论对话对象是否清晰、研究者身份与进入方式。 |
| `basic-science` | 基础科学实验 | 领域主流 SCI 期刊口径 | 选题评估侧重：科学问题的清晰度、表征手段可得性、与已有体系的差异点、发表窗口期。 |
| theory（不支持审查，仅评估） | 理论·数理 | 领域权威期刊/会议口径 | 选题评估侧重：问题的数学意义、假设的强弱与一般性、与已有定理的边界、证明工具是否在手。 |

---

## 三、层级 innovation 标尺片段（按层级替换 `{层级 innovation 片段}` / `{层级 lit}`）

| 层级 | 名称 | innovation 片段 | lit |
|---|---|---|---|
| `bsc` | 本科毕设 | 规范性优先于创新性：结构完整、格式规范、逻辑自洽、可顺利答辩。 | 15-30 篇 |
| `master` | 硕士论文 | 需要「一定创新」：在方法/数据/视角上至少一点新意，文献综述要有深度。 | 50-80 篇 |
| `phd` | 博士论文 | 系统性创新：明确的原创贡献，创新点须贯穿全文并逐章兑现。 | 150 篇以上 |
| `journal` | 期刊投稿 | 边际贡献明确：相对文献矩阵的增量贡献要能一句话说清。 | 以综述需要为准 |
| `general` | 一般性研究 | 以把问题讲清楚为准：重在问题清晰、逻辑完整、证据充分，不预设创新标尺。 | 以论证需要为准 |

## 四、完整拼装示例（quant + journal + 移动支付与农户创业）

> 这是研墨平台同款演示案例，可直接用来验证拼装结果。

```
你是科研选题评审专家（定量实证范式，JF/JFE/RFS 或国内顶刊口径）。研究主题：「移动支付与农户创业」。
全球发文趋势（年份:篇数）：2021:312, 2022:358, 2023:401, 2024:455。

选题评估侧重：识别策略的可行性与数据可得性、边际贡献是否清晰、内生性风险。

用户层级：期刊投稿——创新标尺：边际贡献明确：相对文献矩阵的增量贡献要能一句话说清。文献规模预期：以综述需要为准。

请输出一份选题评估报告，包含：
一、三个候选题目（每题一句话说明研究角度与创新点，编号 1-3）
二、每个题目打分：新颖性(1-10)、可行性(1-10)、数据/材料可得性(1-10)，各一句理由
三、数据与文献可得性清单：这个题目需要什么数据或材料、核心文献大概在哪些库
四、主要风险与规避建议（2-3 条）

用简体中文，条理清晰，可直接作为选题报告使用。
```

## 五、agent 使用注意

1. **趋势数据要真实**：先从 `scripts/topic_radar.py` 拿到真实逐年发文量再填入，不要编造年份:篇数。
2. **中文主题转英文检索**：OpenAlex 是英文库，"移动支付与农户创业" 须用 "mobile money rural entrepreneurship" 跑趋势，评估提示词里主题可保留中文。
3. **三维必须分开打分**：每维理由要回扣该范式关切（见 `topic-scoring-dimensions.md`），不能所有维度写套话。
4. **理论·数理范式**：可做选题评估，但要在评估末尾追加一句"本技能规则库不支持理论论文的后续审查"。
