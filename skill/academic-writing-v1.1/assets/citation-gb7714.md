# GB/T 7714—2015 参考文献著录速查

> 依据：《信息与文献 参考文献著录规则》GB/T 7714—2015；适用：中文期刊、中文学位论文、国内会议论文与基金报告。
> 核心特征：**顺序编码制** + **文献类型标识**（`[M]`/`[J]`/`[D]`…），这是与英文体系的根本差异——缺标识是中文稿件最常被打回的格式问题。

## 1. 正文标注

- 采用**顺序编码制**：按正文首次出现顺序编号，序号置于**右上角方括号**内。
- 例：`已有研究表明该方法有效[3]。`
- 作为句子成分时与正文平排：`由文献[3]可知……`
- 多篇并列：`[3-5]` 或 `[3,5,7]`
- **文内序号与文末条目必须一一对应，数量一致**。

## 2. 文献类型标识码（必填）

| 标识 | 文献类型 | 标识 | 文献类型 |
|---|---|---|---|
| `[M]` | 专著（图书） | `[J]` | 期刊文章 |
| `[C]` | 论文集、会议录 | `[D]` | 学位论文 |
| `[N]` | 报纸文章 | `[R]` | 报告 |
| `[S]` | 标准 | `[P]` | 专利 |
| `[A]` | 论文集中的析出文献 | `[G]` | 汇编 |
| `[DB]` | 数据库 | `[CP]` | 计算机程序 |
| `[EB]` | 电子公告 | `[Z]` | 其他 |

**载体标识**（电子资源必备）：`OL` 联机网络、`CD` 光盘、`MT` 磁带、`DK` 磁盘。
组合写法：`[J/OL]` 网上期刊、`[EB/OL]` 网上电子公告、`[M/CD]` 光盘图书、`[DB/OL]` 网上数据库。

## 3. 各类文献著录格式

### 3.1 专著
```
[序号] 主要责任者. 题名[M]. 版本项(第1版不注). 出版地: 出版者, 出版年: 引文页码.
```
例：`[1] 刘国钧, 王连成. 图书馆史研究[M]. 北京: 高等教育出版社, 1979: 15-18.`

### 3.2 期刊文章
```
[序号] 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```
例：`[2] 袁庆龙, 候文义. Ni-P合金镀层组织形貌及显微硬度研究[J]. 太原理工大学学报, 2001, 32(1): 51-53.`

### 3.3 论文集中的析出文献
```
[序号] 析出文献主要责任者. 析出文献题名[A]//原文献主要责任者. 原文献题名[C]. 出版地: 出版者, 出版年: 起止页码.
```
例：`[3] 钟文发. 非线性规划在可燃毒物配置中的应用[A]//赵炜. 运筹学的理论与应用[C]. 西安: 西安电子科技大学出版社, 1996: 468.`

### 3.4 学位论文
```
[序号] 主要责任者. 题名[D]. 保存地: 保存单位, 年份.
```
例：`[4] 赵天书. 诺西肽分阶段补料分批发酵过程优化研究[D]. 沈阳: 东北大学, 2013.`

### 3.5 报纸文章
```
[序号] 主要责任者. 题名[N]. 报纸名, 出版日期(版次).
```
例：`[5] 谢希德. 创造学习的新思路[N]. 人民日报, 1998-12-25(10).`

### 3.6 标准
```
[序号] 标准编号, 标准名称[S]. 出版地: 出版者, 出版年.
```
例：`[6] GB/T 7714—2015, 信息与文献 参考文献著录规则[S]. 北京: 中国标准出版社, 2015.`

### 3.7 专利
```
[序号] 专利申请者或所有者. 专利题名: 专利国别, 专利号[P]. 公告日期.
```
例：`[7] 姜锡洲. 一种温热外敷药制备方案: 中国, 88105607.3[P]. 1986-07-26.`

### 3.8 电子文献
```
[序号] 主要责任者. 题名[文献类型/载体类型]. (发表或更新日期)[引用日期]. 获取路径.
```
例：`[8] 李强. 化解医患矛盾需釜底抽薪[EB/OL]. (2012-05-03)[2013-03-25]. http://example.com/xxx.`
**引用日期不可省**——这是中文稿件最常见的漏项。

## 4. 作者著录规则

- **3 人以内全部列出**，用逗号分隔。
- **超过 3 人只列前 3 人**，其后加 `, 等`（中文）或 `, et al`（英文文献）。
- 责任者姓名**中文用全名**，**英文用"姓全大写 + 名首字母"**，如 `TENOPIR C`。
- 无责任者时题名前置，不写"佚名"。

## 5. 十条自查

- [ ] 每条文献都有**类型标识** `[M]`/`[J]`/`[D]`/`[EB/OL]` 等
- [ ] 电子文献有**引用日期** `[YYYY-MM-DD]`
- [ ] 正文右上角方括号序号与文末条目**数量一致、顺序一致**
- [ ] 期刊条目有"年, 卷(期): 起止页码"三段齐全
- [ ] 专著有"出版地: 出版者, 出版年"，**出版地不可省**
- [ ] 超过 3 位作者是否正确用"等"/"et al"
- [ ] 学位论文标注了**保存地**与保存单位
- [ ] 析出文献用 `[A]//` 连接论文集
- [ ] 标点用**半角句点 + 空格**，不用中文逗号混排
- [ ] 同一篇文献多次引用：正文沿用首次序号，页码在条目中依次列出

## 6. 与英文体系的对照

| 项目 | GB/T 7714 | IEEE | APA 7 |
|---|---|---|---|
| 文内形式 | 右上角 `[1]` | `[1]` | `(Author, 2023)` |
| 文末顺序 | 出现顺序 | 出现顺序 | 字母序 |
| 类型标识 | **必需** | 无 | 无 |
| 作者倒序 | 中文全名 / 英文姓大写 | 缩写在前 | 姓倒序 |
| DOI | 可选 | `doi: 10.xxxx` | `https://doi.org/` |
| 引用日期 | 电子文献必需 | 仅网页 | 仅变动内容 |

> 中文期刊常要求"中英文对照"参考文献表，即中文条目后附英文翻译。若目标期刊有此要求，须逐条补译，不可只译题名。
